Introducere în dezvoltarea paginilor web

Ce este Web Development?

Web development înseamnă crearea și dezvoltarea site-urilor web. Pentru început, putem folosi HTML, CSS și JavaScript.

HTML

HTML este folosit pentru structura unei pagini web.

CSS

CSS este folosit pentru aspectul și designul paginii.

JavaScript

JavaScript face pagina mai interactivă.

Învață pas cu pas dezvoltarea web.
